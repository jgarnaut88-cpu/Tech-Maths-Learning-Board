# Tech Maths Learning Board

An interactive digital shift board / exam revision tool for university-level Technical Mathematics (MATH11160 or similar).

### Features
- Covers Weeks 1–12 (Full course content)
- Real past exam questions with worked solutions
- Self-marking practice mode
- Formula sheet and method decision guide
- Built as a single-file React app for easy use

### How to Use
1. Open the live version (link below)
2. Select a week/topic from the left sidebar
3. Work through questions, check answers, and track progress
